# 寒潮王座 · 冬境日常CG素材库

这是为交互式末日视觉小说建立的**候选日常CG管理站**。人物素材按原游戏外观归类，**暂不绑定**小说人物。

## 数据与功能
- `index.html`：浏览、搜索、分组、编辑、候选收集、JSON导入导出。
- `data/catalog.json`：共享素材目录；当前仅包含少量候选外链图片，尚未完成 10 组 × 10 张人工审核。
- 支持人物组独立管理、同图关联多个候选、场景动作服饰和来源标签、人工精选。

## 部署

**本 GitHub 仓库保持 Private。** 要让任何人公开访问网站，需要将此私有仓库连接到 Vercel 等静态站点托管服务，由托管服务将本仓库部署为公开网页。Vercel 控制台可选择 Import Git Repository，然后选择当前仓库，项目预设 Other，部署根目录 `/`，无需编译命令。

注意：私人仓库内容不会直接被匿名访问；只有发布构建中的网站、静态素材和 `data/catalog.json` 是公开的。

## 日常编辑与更新

网站支持浏览器本地草稿和 JSON 导入导出；点击「在线发布」可以使用**仅针对本仓库的细粒度 GitHub 令牌**，将更改提交到 `data/catalog.json`。仅仓库拥有者/授权编辑者应使用此功能。令牌仅保存在页面会话内存，请不要输入来源不明的网页，也不要提交令牌进仓库。

在 Vercel 正确绑定 GitHub 自动部署后，推送到 main 的更改会触发一次新部署，公开网站显示新目录。公开访问者只能浏览，并不会获得对私人 GitHub 仓库的写入权限。

如果上传授权图片到 `assets/`，图片在公开部署后可通过相对路径访问；**仅有链接不代表拥有图片再分发许可**。该图库仍是素材挑选原型，正式使用第三方游戏CG或同人作品应核实相关版权。

## 注意事项
- 不要把未人工审核的检索结果凑作“已完成120张”。
- 公开网页不能保密其已展示的图片、链接和素材数据。
- 本项目仓库私有并不自动意味着公开网站已上线；部署必须另行完成。

## 由 ChatGPT 直接维护（主要工作方式）

本项目的内容维护以**当前已连接的 GitHub 私有仓库**为准。你可以在 ChatGPT 里直接说：

- “为 N-04 人物外观组增补符合日常生活剧情的 10 张候选CG，给出原作者/原链接。”
- “删除图 S-003，把 S-008 归到 N-05，同时加入厨房、共同用餐标签。”
- “把首页调整成更适合视觉小说的横向CG画廊。”
- “核对本轮 GitHub 提交是否生效。”

ChatGPT 使用已授权的 GitHub 连接读取、更新仓库文件并提交，不需要用户把 GitHub Token 发在聊天中。每次修改后应提供 GitHub 提交结果，说明更改数量、尚未验证的内容以及网站是否已完成实际公开部署。

### 唯一的共享数据来源

- `data/catalog.json`：**线上图片目录的权威文件**，存 `groups` 和 `images`。ChatGPT 调整候选图片、角色外观组、来源和标签时，优先修改这个文件。
- `index.html`：网站样式、筛选器、交互界面。网站功能/外观调整时修改。
- `assets/`：自有或获得公开展示许可的图片文件；素材数据库通过 `./assets/xxx.webp` 等相对路径引用。
- `vercel.json`：公开静态站部署配置，保持 GitHub 仓库本身私有。

### 数据规则

- `groupIds` 是多对多；同一幅多人CG可归入多个候选组。
- 候选外观不等于《寒潮王座》正式剧情人物；未获得明确指定前不得自动绑定。
- 自动检索图片必须先标记为 `candidate`，只在真正查看并确认符合条件后标记为 `approved`。
- 日常CG要有环境与动作，不得用单纯站立立绘充数。
- 编辑现有图片时保留稳定 `id`、原始作者来源 `source`、许可状态 `copyright`，新图使用唯一 ID。
- 新图片默认带 `groupIds`、`title`、`url`、`source`、`tags`、`status` 和 `copyright`，完整信息见仓库已有条目。
- 更新文件时可相应更新顶层 `updatedAt`；避免改写无关图片记录与角色组。

### 网站内容刷新

从联网公开网站首次载入时，若没有本地草稿，会从 `data/catalog.json` 获取最新共享数据。如果浏览器中有个人编辑草稿，网页会优先保留草稿并显示“本地草稿”状态。点击页面的「↻ 同步最新」按钮，可在确认后丢弃本地草稿并载入 Vercel 已经部署的最新 `data/catalog.json`。

网站网页内的 GitHub 编辑是**另一种可选工作流**，需要管理者自行授权；但 ChatGPT 通过已连接的 GitHub 修改仓库时，不依赖这个网页的 Token 表单。

**限制**：ChatGPT 只会在收到指令并执行操作时修改仓库，不会无条件在对话之外自动继续工作。GitHub 成功提交不等于 Vercel 已完成部署；部署状态与公网可用性应分别检查。
