# 代码审计与修复 · 2026-10-22

基线：`a0c8270dabe2010e6f4aa30956a0fc53ed7da090`。范围包括静态图鉴、Spine/Cubism 播放、语音、缓存、导入脚本、预览政策和 CI。

## 已修复

- 文件下载的超时/取消持续覆盖响应体；一个模型的图集失败时同步取消其余骨骼和贴图下载。
- 渲染加载等待真实 success/error；损坏的浏览器缓存删除后重新下载，渲染失败不再当作播放成功写缓存。
- 被新选择取代的运行时注册不销毁当前播放器；取消渲染会结束旧加载 Promise，过期成功回调销毁旧实例。
- IndexedDB 在 transaction complete 后才报告保存成功，并处理 blocked、晚到连接与打开超时。
- 本地缓存、本地文件导入使用选择代次校验；深链接缓存包只发起一次播放，角色 ID 优先。
- 本地骨骼读取实际 Spine 版本，支持界面承诺的 .skel.bytes/.atlas.txt，统一 JSON/atlas 文本的 base64、Unicode 与 3.8/4.x 数据 URI 处理。
- 搜索/服装筛选移除选中角色时，停止旧播放并同步 URL。
- 父页与 Cubism 子页共用语音播放器，在点击事件中同步调用 Audio.play，统一同皮肤重试、取消、超时、音量校验和过期回调隔离。
- Live2D 使用逻辑屏幕坐标适配 HiDPI 画布；拖动偏移在缩放/resize 后保留。
- 隐藏的图鉴轮播停止图片请求；非法 URL hash 不再把成功的目录加载误报为失败；收藏筛选中的详情按钮同步状态。
- Windows 生成的预览 URL 使用正斜杠。
- 修复蔚蓝档案导入脚本的语法断裂与重复尾段；增加所有 Python 维护脚本的语法回归。
- 七个静态导入/镜像流程统一调用本地 composite action，生成缩略图和原图尺寸后运行完整 smoke，再一并提交。导入改为 workflow_dispatch，源码修改由 verify 工作流验证。
- 恢复型 workflow_run 发布仅接受本仓库 main 的成功任务，预览发布串行。
- 修复旧 smoke 脚本的模块顺序、分页及 HTTP 缓存约定；浏览器测试同时验证首屏 96 张和分页后全部 209 套服装。
- 新增无外网依赖的异步行为回归，并接入持续检查。

## 验证

本地：14 项 Node 异步播放回归、11 项 Python 测试、1 项内存缓存回归通过；28 个 Actions YAML 可解析，页面脚本按实际加载顺序可共同解析。

仓库树检查覆盖 2,619 条目录记录及 3,066 个本地图片引用，无缺失路径。提交后的 GitHub 环境已验证 815 张 Spine WebP 的文件摘要，以及 540 张静态立绘的路径、分类和缩略图元数据。

以下六类 Chromium 工作流均在修复后的页面代码上通过：静态原图弹窗、Spine 图集旋转/交互连续性/播放、棕色尘埃2全身动态、碧蓝航线 Cubism、明日方舟动态立绘、其他游戏动画。完整 smoke 的最终结果及单独的全目录扫描状态见 [Actions](https://github.com/tyqittle/anime-character-archive/actions)。

本地未下载全部二进制素材，因此图片摘要和真实 CDN 播放的结果以 GitHub 环境为准。

## 架构边界

静态 Pages 及现有页面 URL 保留。经典 defer 脚本仍共享全局状态；此次以加载代次、事务完成和共同播放模块收紧生命周期，没有在缺少完整端到端覆盖时整体切换 ES Modules。动态素材和部分运行时仍依赖外部资源，其可用性由现有浏览器工作流检测。
