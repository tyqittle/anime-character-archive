# 完整动态图鉴：首轮补全

用户明确要求每个游戏导入全部动态立绘及全部皮肤；不以静态图片补齐，不再按少数成熟角色作精选。完整目标已写入 AGENTS.md，覆盖和缺项见 [全站覆盖清单](DYNAMIC_ENCYCLOPEDIA_COVERAGE.md)。

本轮先扩充两个缺口最大的已接入游戏：

- 天命之子：固定来源 979 个模型设置中，973 个通过全部文件引用核验，6 个缺少资源；由 14 套增加到 973 套。通过固定 Git blob 的角色与皮肤名称表补充名称；没有对应名称时保留源编号。
- 绯色回响：自动发现 344 个独立模型主骨骼，336 个通过源文件、版本及贴图检查，8 个缺少骨骼或图集；由 21 套增加到 336 套。背景骨骼不重复计作角色皮肤。此前因人物过小被排除的完整模型重新纳入索引。

新增索引与实际播放、全量预览是不同状态。原有预览保留；本地核验了旧角色回归，并采集新增代表模型真实预览；剩余预览由共同流水线处理，不能据此宣称全部已通过播放。新增 959 + 315 = 1274 个索引，四个新增代表预览已完成，其余等待共同采集结果。

来源审计保存原始缺文件错误。两个摘要传输异常经重试验证通过；两个完整大骨骼超出原 4MB 预算，明确增加有界预算至 8MB 后通过。失败重试只处理失败项，已核验的相同固定版本条目保留，避免反复下载整库。

首轮全目录盘点另发现：少女咖啡枪 273 个源设置中已索引 64 个；凍京 NECRO 397 个设置中已索引 62 个；少女次元 112 个设置中已索引 102 个。源设置可能包含别名和场景，需按独立动态立绘及皮肤分类后补全，不能直接当作缺失角色总数。LOVE CUBE 和 Sacred Sword Princesses 的未索引源设置也在报告中保留。其他未核对来源的游戏保持未核验状态。

验证：145 项 JavaScript 测试、38 项 Python 测试、架构和冒烟检查；旧的天命之子和绯色回响代表模型双帧运动、动作和缩放回归通过。当前工作是完整图鉴目标的首轮进展，不是整个目标完成。
