# 完整动态图鉴：第二轮补全

范围仍为已接入游戏的全部动态角色立绘和全部皮肤，不用精选样本或静态图片代替。

- 双生视界（少女咖啡枪）：固定来源全部 273 个设置通过文件引用核验，由 64 项增至 273 项。兼容原来的嵌套目录、更新导出目录和四种特殊路径，原有 ID 保留。
- 凍京 NECRO：固定来源全部 397 个设置通过文件引用核验，由 62 项增至 397 项。其中 Cubism3 为 87 项，旧版为 310 项。旧设置有 JSONC、大小写不符、贴图额外 android 子目录、遗漏动作清单等问题；标准化保留全部可用动作，并记录路径修正和补入的同模型动作。

旧版 310 项中 308 项具有可定位的动作文件，另两项没有独立动作文件，保持未验证动态能力状态，不宣传为动画通过。资源完整、索引建立、实际运动和预览是独立状态，来源目录完整也不能证明游戏当前版本所有皮肤均已公开。两款游戏共新增 544 项索引，其他游戏继续按覆盖清单推进。

标准化设置只包含配置，骨骼、贴图与动作仍指向相同固定 GitHub 提交。CDN 对个别完整 MOC 返回 403，因此本批标准化资源使用同版本 GitHub 原始文件。设置 URL 含实际内容 SHA256；动作或资源路径改变时旧预览失效。未借用其他角色的图片或动作。

本地验证：154 项 JavaScript 测试、38 项 Python 测试、架构及冒烟检查通过。六个旧/新代表模型通过实际播放、双帧运动、动作和缩放回归；资源路径调整后复验旧版模型。8 个新增代表预览走统一采集、转换与来源校验后发布，其余由共同流水线逐项处理。并非所有新条目均已证明播放成功。

发布保留最新 main 的桌面相关改动和首轮后台采集结果，不回退上游已有功能或预览。来源盘点见 `data/girlscafegun-full-inventory.json`、`data/tokyonecro-full-inventory.json`；具体导入核验见对应 source-audit 文件。全站覆盖见 [覆盖清单](DYNAMIC_ENCYCLOPEDIA_COVERAGE.md)。

复现：`node scripts/live2d_sources.mjs --scope SCOPE --import SCOPE --output AUDIT`。来源树 API 受限时，可传入从同一固定树 SHA 获取的 `--source-tree SNAPSHOT`；工具拒绝不匹配或截断的树，并独立核对配置的 Git blob 摘要。
