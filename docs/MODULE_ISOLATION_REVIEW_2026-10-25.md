# 模块隔离检查

基线：`b1512faf1a0f59986ca16de4d76e25ecd607a9fa`。本轮使用独立的最新仓库副本，保留原扩充目录的未发布模型和播放器草案。

## 已复现并修复

| 模块交界 | 原行为 | 修复后的边界 |
| --- | --- | --- |
| 缓存 → 播放/桌面状态 | IndexedDB 失败经全局 `status(...,true)` 把正常播放标为错误 | 缓存失败只更新本地缓存控件与诊断，在线播放继续 |
| 两次缓存刷新 | 较旧异步结果覆盖更新的列表 | 只有当前刷新序号可以提交控件结果 |
| 语音 UI → 渲染器清理 | 语音 UI 回调抛错使旧 GPU 会话/iframe 无法继续释放 | 可选通知失败独立记录，渲染器和 iframe 仍被释放 |
| 音频服务 → 状态订阅者 | 订阅者抛错能中断 Audio.play 或被当作音频源失败 | 订阅者通知独立捕获；不替换真实的音频加载/播放失败处理 |
| Cubism 加载 → 下一个模型 | 上个 setup 持续占用计时器和候选模型直至超时 | 切换立即结清旧 setup、销毁旧候选，迟到成功不能提交 |
| 旧模型事件 → 新模型 | 旧 pointer 回调通过全局 `model` 拖动新模型 | 回调同时核验加载代次和模型实例归属 |
| 桌面桥接 → 画布 | 已释放 WebView 宿主的 postMessage 异常向上传播 | 消息传输失败记录诊断，画布继续；协议字段不变 |

七条行为故障用例在修复前失败，修复后通过。测试入口为 `tests/test_module_isolation.mjs`，覆盖失败、并发返回与迟到回调，而非仅检查源码字符串。

另发现 Windows 的 Git CRLF 自动转换会改变内容寻址的模型设置字节，令设置 URL 的 SHA-256 与实际文件不一致。`.gitattributes` 对 `assets/model-settings/**` 禁止文本转换；已通过 Git 原始 blob 核对恢复本地字节，没有修改模型设置内容或目录身份。

## 可持续约束

缓存事务由无 DOM 的 `shared/indexeddb-storage.js` 服务拥有，使用显式 opener 输入。旧 `winter-spine-local-v1` 数据库名、`packs` 表和 `dbAction` 调用兼容。目录模块只保留 UI 和经典脚本兼容委托。

`npm run check` 增加 `module_boundaries.mjs`：共享服务不得反向访问页面 DOM、选择状态或具体引擎实现；Spine/Cubism/图鉴入口不得互载对方的播放器；缓存服务必须先于目录 UI 初始化。`friend-links.js` 明确属于显示组件，保留其 DOM 访问。结构检查只是补充，主要证据仍为行为回归和真实浏览器故障注入。

父入口、iframe URL 与受影响脚本使用一致的新缓存版本；未修改的桌面启动协议和其他脚本保留其既有版本。

## 验证与限制

- 本地 202 项 Node、42 项 Python、架构/集成与仓库卫生检查通过；4,684 项目录记录、资源身份、默认链接和预览摘要兼容检查通过，新增/删除均为 0。
- `scripts/test_module_isolation_browser.mjs` 使用真实 Spine/Cubism，模拟单个目录 503、IndexedDB 不可用、语音 UI 失败、旧 MOC 请求迟到和桌面消息接收端已释放；继续核对模型 ID、双帧动态与跨引擎切换。
- 真实浏览器故障回归已接入现有动画验证工作流的独立任务，不依赖某款游戏的完整资源检查先通过；沿用统一编排与报告。
- 没有增加、删除或替换角色/皮肤，也未改变模型地址、收藏键或素材缓存身份。

现有经典脚本仍共享部分会话变量，Spine 不同运行时仍通过受序列化的全局命名空间切换；`catalog.js` 仍承担部分列表/映射/UI。不能据此宣称整站已消除所有耦合。后续继续按职责迁移，以行为和失败路径验证替换入口，避免一次重写所有播放器。
