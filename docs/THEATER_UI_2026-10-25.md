# 动态图鉴界面与浏览交互

本轮在最新主分支的剧场样式上补全浏览交互，保留模型 ID、旧链接、资源、截图身份和浏览器存储键。

## 使用路径

- 游戏目录提供可搜索的游戏面板；菜单数量来自实际去重后的可选外观，不代表整个游戏收录完整或逐项播放通过。
- 角色搜索支持现有中文、英文、编号及皮肤字段；无结果时可一键清除全部筛选。
- 浏览游戏、输入搜索不会停止当前舞台；点击卡片或上一位、下一位、随机按钮才切换角色。连续浏览以当前筛选全集为范围，包含尚未翻页显示的卡片。
- 舞台底部提供目录、连续浏览、随机、缩放、适应画面、设置；右侧设置默认收起，沿用已有侧栏偏好。
- 手机侧栏覆盖舞台，选中后关闭；点击遮罩或 Escape 可关闭。全屏可保留舞台内快捷栏。
- 快捷键：左右方向键切换，B 浏览，T 设置，F 全屏，0 适应。输入框、可编辑区域、按钮、链接以及游戏弹窗内保持原生键盘行为。

## 模块职责

`assets/js/spine/theater-experience-v2.js` 是页面呈现适配器，复用现有选择、播放和工具命令；不拥有渲染器、模型、下载或存储。目录通过 `setCatalog(filtered)` 和 `setSelection()` 通知呈现层。呈现适配器未加载时旧目录及工具仍可使用。

`panel-layout.js` 只管理侧栏，`theater-ui.js` 的原有工具接口保持不变。桌面宿主隐藏新增舞台装饰和遮罩，透明画布与桌面协议不变。渲染器回归使用 `theater_browser_helpers.mjs` 显式展开其需要检查的设置。

窄屏切换时 Live2D 的 resize 回调先调用 PIXI 的同步画布尺寸更新，再用新的逻辑尺寸取景，避免 PIXI 延迟更新导致人物仍按旧宽度居中。父入口、iframe URL 和子入口使用共同的 `20261025-live2d-responsive-fit-v12` 版本。

## 验证

- Node 行为测试、Python 测试、模块边界与集成检查。
- 目录兼容检查：4,684 条原始记录均保持，未增删资源或预览。
- `scripts/test_theater_experience_browser.mjs` 验证游戏搜索、角色筛选、连续/随机浏览、输入快捷键隔离、全屏、缩放、真实实例保留、390 px 手机侧栏以及桌面宿主 UI 隐藏。
- 真实播放样本：Spine `ec-60010003`，Cubism `al-beierfasite_2`；以两帧像素变化核验动画，同时测试快捷缩放及适应画面。
- 既有 `test_module_isolation_browser.mjs` 验证可选缓存、目录、语音与宿主异常，以及过期模型请求隔离。

本轮没有逐一重播全部模型，没有变更原生 Windows 行为；网站 UI 隐藏检查不能替代客户端安装及启动验收。浏览器截图与诊断输出保存在忽略的 `tmp/theater-experience/`。
